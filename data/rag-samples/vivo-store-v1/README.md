# vivo 授权店 AI客服 RAG 样本 v1

这是用于验证 Markdown 入库、检索和回答效果的最小样本，不是 vivo 官方资料库。

## 范围

- 商品样本：vivo Y200、vivo Y300 Pro、vivo S19、vivo S20、vivo X200、vivo X200 Pro、vivo X Fold3 Pro。
- 事实来源：仅使用对应机型的 vivo 中国官网规格参数页。
- 资料快照：2026-08-11。
- 店铺规则和实时价格尚未纳入本样本；文档中的建议零售价均为官网页面列出的上市价格，不代表当前成交价。

## 目录说明

- `knowledge/products/`：可用于后续 Markdown 入库的商品知识文档。
- `evaluation/test-cases.jsonl`：27 条独立验证题，严禁作为知识库文档上传。

## 使用约束

- 每份商品文档同时包含官网事实和固定店铺导购口径，两者会明确标注。
- 官网没有列出的能力一律标为“官方参数页未列出”，不能转换为“支持”或“不支持”。
- 回答涉及价格时，必须说明这是资料快照中的官网上市价格；实时库存、优惠和成交价不在本样本范围内。
