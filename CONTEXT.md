# Knowledge Ingestion Context

## Glossary

| Term | Meaning |
| --- | --- |
| Source Document | The original user-uploaded file, such as a PDF, DOCX, PPTX, XLSX, or image. |
| Parsed Markdown | The structured Markdown generated by MinerU from a Source Document. It is the only text input to the RAG chunking pipeline for MinerU-supported files. |
| Indexed Document | The L1/L2 parent chunks and L3 leaf chunks derived from a Parsed Markdown file and stored for retrieval. |
| Rich Document | A PDF, DOCX, PPTX, XLSX, or supported image. Rich Documents must be parsed by MinerU. |
| Native Text Document | A Markdown, TXT, or HTML file. It bypasses MinerU and enters the existing text/HTML parsing path. |
| Parsed Artifact Bundle | The persisted MinerU output for one Rich Document: Markdown, extracted images, and `content_list_json`. Only its Markdown is indexed in the first release. |
| Document Replacement | Uploading a Source Document with an existing filename removes the prior source file, Parsed Artifact Bundle, and indexed chunks before indexing the new upload. No version history is kept in the first release. |
| Parsing Profile | The server-owned, environment-configured MinerU parameter set used for all Rich Documents. It is not user-selectable in the first release. |
| Ingestion Job | The single-process background job that converts, chunks, and indexes an upload. It exposes upload, cleanup, MinerU conversion, chunking, parent storage, and vector storage progress; it does not survive an application restart in the first release. |
| Replacement Staging | The temporary source file, Parsed Artifact Bundle, and chunks prepared for a same-name upload before the existing indexed document is removed. A failed preparation leaves the existing document available. |
