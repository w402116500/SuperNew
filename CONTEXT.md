# Knowledge Ingestion Context

## Glossary

| Term | Meaning |
| --- | --- |
| Source Document | The original user-uploaded file, such as a PDF, DOCX, PPTX, XLSX, or image. |
| Parsed Markdown | The structured Markdown generated by MinerU from a Source Document. It is the only text input to the RAG chunking pipeline for MinerU-supported files. |
| Indexed Document | The L1/L2 parent chunks and L3 leaf chunks derived from a Parsed Markdown file and stored for retrieval. |
